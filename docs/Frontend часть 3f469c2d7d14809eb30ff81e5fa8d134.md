# Frontend часть

Пользователь может зарегистрироваться и войти в аккаунт, загрузить аудио или видео, запустить обработку, отслеживать её статус, просматривать транскрипцию и результаты анализа, работать с историей записей, папками и тегами, экспортировать результаты и задавать вопросы AI по конкретной записи.

Frontend напрямую работает только с основным Backend:

**React Frontend → Main Backend → ML Backend**

Frontend не должен знать, какие ML-модели используются внутри системы. Он получает от Backend уже готовые статусы, транскрипции, результаты анализа и ответы AI-чата.

Основная задача frontend — предоставить удобный интерфейс для полного пользовательского сценария от загрузки файла до работы с результатами.

# Загрузка записи

```
POST /api/v1/records
```

Multipart:

```
file: meeting.mp3
name: Еженедельная встреча
folderId: optional
tags: optional
```

Response:

```
{
  "id": "record-123",
  "name": "Еженедельная встреча",
  "status": "UPLOADED"
}
```

После успешной загрузки frontend может перенаправить пользователя на страницу записи.

# AI-чат

Отправка вопроса:

```
POST /api/v1/records/{recordId}/chat/messages
```

Request:

```
{
  "message": "Какие решения приняли на встрече?"
}
```

Response:

```
{
  "messageId": "msg-123",
  "answer": "Было принято решение...",
  "sources": [
    {
      "start": 540.2,
      "end": 580.6
    }
  ]
}
```

История:

```
GET /api/v1/records/{recordId}/chat/messages
```

Frontend должен уметь по `sources` перейти к нужному месту записи.

# Real-time обновления

Если используется SSE:

```
GET /api/v1/records/{recordId}/events
```

Frontend получает события:

```
{
  "status": "PROCESSING",
  "stage": "ANALYZING",
  "progress": 78
}
```

Если SSE/WebSocket ещё не реализован, frontend использует polling.

# Основной User Flow

```
Пользователь
    ↓
Открывает Web
    ↓
Авторизация
    ↓
Главный экран
    ↓
Загрузка файла
    ↓
Frontend → Backend
    ↓
Файл загружается
    ↓
Запускается обработка
    ↓
Frontend отслеживает статус
    ↓
COMPLETED
    ↓
Страница результата
    ↓
┌─────────────────────┐
│ Транскрипция        │
│ Summary             │
│ Темы                │
│ Решения             │
│ Задачи              │
└─────────────────────┘
    ↓
Редактирование / экспорт / AI-чат
    ↓
История / папки / теги
```
