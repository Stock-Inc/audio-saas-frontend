### Основное разделение

`frontend/` — React веб-приложение.

`mobile/` — Android-приложение.

`backend/` — основной Spring Boot backend: пользователи, авторизация, файлы, история, папки, теги, результаты, чат, интеграция с ML.

`ml-service/` — Spring Boot ML-микросервис: управление ML pipeline, jobs, GPU profiling, выбор preset, взаимодействие со STT и LLM.

`ml-worker/` — Python/inference-часть для WhisperX, diarization и работы с моделями, которые удобнее запускать вне JVM.

`shared/api-contracts/` — контракты между сервисами. Это особенно важно, чтобы backend и ML-разработчики работали независимо.

`infrastructure/` — PostgreSQL, Redis, nginx, мониторинг и окружение.

`docs/` — архитектура, диаграммы, требования и описание API.
