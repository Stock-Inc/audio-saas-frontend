# Фронт
TypeScript + React с использованием компонентов shadcn/ui.

Для конвертации файлов используется ffmpeg.

Авторизация через куки.

## Запуск
### Без докера
Для запуска необходимо установить переменную окружения VITE_BACKEND_URL.

Затем `bun dev`

### Docker
`docker build --build-arg VITE_BACKEND_URL=<адрес бекенда>

### GHCR
Т.к. vite встраивает переменные окружения во время сборки, а ghcr распространяет готовые контейнеры, изменить адрес бекенда получится только при пересборке самого контейнера на ghcr. В данный момент это localhost:8081.
